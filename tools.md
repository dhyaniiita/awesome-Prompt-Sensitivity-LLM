# Tools and Libraries

The course requires at least five tools/resources. These six are directly relevant to prompt testing, evaluation, reproducibility, and experiment comparison.

1. **LM Evaluation Harness** — Standardized and custom LLM evaluation with explicit prompts, tasks, metrics, and multiple model backends. [GitHub](https://github.com/EleutherAI/lm-evaluation-harness)
2. **HELM** — Stanford CRFM framework for holistic, reproducible, transparent evaluation. [GitHub](https://github.com/stanford-crfm/helm)
3. **PromptSource** — Toolkit for creating, sharing, and applying natural-language prompt templates. [GitHub](https://github.com/bigscience-workshop/promptsource)
4. **promptfoo** — LLM testing, prompt comparison, evaluation, and red-teaming toolkit. [GitHub](https://github.com/promptfoo/promptfoo)
5. **OpenAI Evals** — Framework and registry for building and running LLM evaluations. [GitHub](https://github.com/openai/evals)
6. **LangSmith Evaluation** — Dataset-based evaluation, experiment comparison, and evaluator workflows. [Documentation](https://docs.langchain.com/langsmith/evaluation-quickstart)
