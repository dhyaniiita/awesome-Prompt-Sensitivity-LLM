## Part 4 — Easiest upload method: GitHub Desktop

If you are completely new to Git, GitHub Desktop is the easiest method for the required five commits.

1. Download GitHub Desktop from https://desktop.github.com/
2. Install it.
3. Open GitHub Desktop.
4. Sign in with your GitHub account.
5. Choose `Clone a repository from the Internet`.
6. Select your account and the repository `awesome-prompt-sensitivity-llm`.
7. Choose a local folder you can find easily, such as Documents/GitHub.
8. Click `Clone`.
9. Open the cloned repository folder in File Explorer.
10. Extract this ZIP somewhere else.
11. Copy the prepared repository contents into the cloned repository folder. Do NOT copy the outer ZIP file itself.
12. If Windows asks whether to replace README.md, use the prepared package's README.md.
