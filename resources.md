# Tutorials and Learning Resources

The course requires at least five learning resources. These seven are authoritative or project-maintained resources.

1. **ACL Anthology** — Scholarly portal for computational linguistics papers, proceedings, and metadata. [ACL Anthology](https://aclanthology.org/)
2. **LM Evaluation Harness documentation** — Installation, tasks, prompts, model backends, and evaluation workflows. [GitHub](https://github.com/EleutherAI/lm-evaluation-harness)
3. **HELM documentation** — Practical material for transparent, multi-dimensional LLM evaluation. [GitHub](https://github.com/stanford-crfm/helm)
4. **PromptSource documentation** — Prompt templating and prompt experimentation workflows. [GitHub](https://github.com/bigscience-workshop/promptsource)
5. **OpenAI Evals: Building an eval** — Step-by-step guide to datasets, eval registration, and execution. [Guide](https://github.com/openai/evals/blob/main/docs/build-eval.md)
6. **LangSmith Evaluation Quickstart** — Practical dataset, evaluator, experiment, and comparison workflow. [Guide](https://docs.langchain.com/langsmith/evaluation-quickstart)
7. **promptfoo documentation** — Practical LLM testing, evaluation, and red-teaming workflows. [Documentation](https://www.promptfoo.dev/docs/)
