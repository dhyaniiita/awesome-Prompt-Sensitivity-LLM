# GitHub Implementations

The course requires at least five existing implementations. These seven were selected for their connection to prompt sensitivity, consistency, evaluation bias, or reproducible LLM evaluation.

1. **Ordered-Prompt** — Code for the ACL 2022 few-shot prompt-order sensitivity study. [GitHub](https://github.com/yaolu/ordered-prompt)
2. **ParaRel** — Code and data for paraphrase-based consistency experiments. [GitHub](https://github.com/yanaiela/pararel)
3. **LPAQA** — Prompt/query resources for factual knowledge extraction and LAMA-style probing. [GitHub](https://github.com/jzbjyb/LPAQA)
4. **FairEval** — Implementation associated with positional bias in LLM evaluation. [GitHub](https://github.com/i-Eval/FairEval)
5. **FastChat** — Includes MT-Bench and LLM-as-a-judge evaluation workflows. [GitHub](https://github.com/lm-sys/FastChat)
6. **LM Evaluation Harness** — General-purpose benchmark and prompt evaluation framework. [GitHub](https://github.com/EleutherAI/lm-evaluation-harness)
7. **HELM** — Holistic, transparent evaluation framework from Stanford CRFM. [GitHub](https://github.com/stanford-crfm/helm)

## Selection criteria

The course asks students to examine documentation quality, code availability, maintenance/activity, examples, reproducibility, license, and connection to a paper or recognized project before selecting GitHub resources. Perform a final click-through of each repository before submission.
